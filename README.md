# 🎓 Meridian University Website

A modern and responsive university website developed for Meridian University as a course project.

## 📖 About the Project

The Meridian University Website is a collaborative front-end development project created as part of a web development course.

The project provides a clean and user-friendly interface where students and visitors can explore university information, courses, and contact details.

## 🎯 Project Goals

The main goals of this project are:

- Practice front-end web development
- Create a responsive university website
- Practice HTML, CSS, Bootstrap, and JavaScript
- Learn Git and GitHub
- Practice teamwork and collaborative development
